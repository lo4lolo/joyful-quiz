퀴즈를 즐겁게, 배움은 깊게

아이들은 게임처럼 즐겁게 퀴즈를 풀고, 선생님은 정답률·오개념·응답 시간·다시 만난 문제·게임 속 행동·모둠 협력을 분석실에서 살펴 다음 수업을 설계해요. 골든벨부터 전통놀이 모둠 협력 게임까지 단원 정리에 맞게 골라 쓸 수 있어요.

크롬북·태블릿·컴퓨터 · 학생 설치와 회원 가입 없음. 카트는 최대 40명이며, 실제 기기·네트워크에서 사전 확인하세요.

  2. 전개 15분 · 💰 보물 상자 — 각자 자기 속도로 단원 전체 문제를 반복해요.틀린 문제는 다시 나오니 자연스럽게 복습돼요.
  3. 정리 15분 · 🏎️ 카트 레이스 또는 🚩 땅따먹기 — 신나게 마무리!퀴즈 도장이 있어 문제를 피하고 달릴 수 없어요.
  4. 수업 뒤 · 📊 분석실 — 다시 가르칠 문제 TOP 3, 오개념 후보, 도움이 필요한 학생을 확인해요.AI 도움 프롬프트로 다음 차시 계획까지 쉽게.

수업 준비 순서

  1. 퀴즈 세트 만들기 — 보관함에서 새 세트를 누르고 표에 문제를 써요. 오답까지 쓰면 객관식, 정답만 쓰면 단답형, O·X는 OX.엑셀 양식으로 한꺼번에 올리거나 엑셀에서 여러 줄을 복사해 붙여넣어도 돼요. 오른쪽에 학생 화면 미리보기가 보여요.
  2. AI로 만들기 — 학년·과목·문제 모양을 고르면 요청문이 완성돼요. 복사해서 교과서 쪽과 함께 AI에 보내고, 받은 엑셀을 올려요.정답은 꼭 한 번 확인해요.
  3. 게임 고르기 — 11가지 게임 상자 중 하나를 누르고 설정을 정해요. 재미있는 별명을 켜면 친구들 화면에는 별명이, 선생님 기록에는 입력한 이름이 남아요.
  4. 방 열기 → 게임 시작 — TV에 주소·게임 코드·QR이 크게 나와요. 학생 스티커가 다 모이면 게임 시작. 다 들어오면 입장 잠금.
  5. 결과 — 순위와 문제별 정답률이 나오고 기록(JSON+엑셀) 저장을 시도해요. 결과 화면과 실제 파일을 확인해 주세요. 한 판 더 또는 다른 게임 고르기로 이어 해요.

학생 주소

이렇게 들어가요

  1. 주소에 들어가거나 QR을 찍고 게임 코드 4자리를 써요.
  2. 번호와 이름을 쓰고 컴퓨터인지 태블릿인지 골라요. 선생님이 별명 모드를 켜면 친구들에게는 재미있는 별명으로 보여요.
  3. 스티커 친구를 고르고 바탕색·모자를 꾸민 뒤 준비 완료!
  4. 게임이 끝나면 칭찬 도장을 받아요. 도장 10개로 스티커 뽑기를 해서 희귀·전설 친구를 모아요. 스티커북은 이 기기에만 저장돼요.

📊 분석실

  1. 게임이 끝나면 결과 화면의 📊 분석실에서 자세히 보기를 눌러요.방금 끝난 기록이 바로 열려요.
  2. 지난 기록은 기록 파일 열기로 여러 개를 한꺼번에 열어요. 같은 이름의 학생은 합쳐서 단원 전체를 볼 수 있어요.
  3. 다시 가르칠 문제 TOP 3, 오개념 후보(많이 고른 오답), 학생×문항 표, 차시 비교를 확인해요.
  4. 🤖 AI 도움에서 다음 차시 수업 설계·보충 문제 만들기 프롬프트를 복사해요. 학생 이름은 자동으로 가려져요.
  5. 엑셀로 저장하거나 인쇄해서 협의회 자료로 써요.

🔒 학생 기록은 선생님 컴퓨터에만

  1. 학생 이름과 답은 수업하는 동안에만 서버 메모리에 잠깐 있어요. 서버의 하드디스크나 데이터베이스에 저장하지 않아요.
  2. 선생님이 새 방 만들기로 방을 닫으면 곧바로 지워지고, 닫지 않아도 4시간이 지나면 자동으로 지워져요.
  3. 결과는 선생님 컴퓨터에 파일(JSON 기록 + 엑셀)로 저장돼요. 분석실은 이 파일을 브라우저 안에서만 열고, 어디로도 보내지 않아요.
  4. 학생은 회원 가입이 없고, 번호와 이름(또는 별명)만 써요. 실명 대신 번호만 써도 돼요.
  5. AI 프롬프트에는 학생 이름 대신 ‘학생 A, 학생 B’로 들어가요. 학교에서 허용한 AI 서비스를 써 주세요.
