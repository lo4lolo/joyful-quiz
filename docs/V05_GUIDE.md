# 즐거운 퀴즈 v0.5 사용 안내

## 시작하기
`시작하기.cmd`를 더블클릭하세요. 서버가 준비되면 선생님 보관함이 열립니다. 창을 닫으면 수업 연결도 끝납니다. 기본 주소는 `http://localhost:3030/teacher.html`입니다.

## 혼자 카트 연습
보관함의 **혼자 카트 연습**을 누르세요. 학생 초대나 방 생성 없이 예시 문제 또는 내 세트로 연습할 수 있습니다.

1. 문제 세트, 트랙, 키보드/화면 버튼을 선택합니다.
2. **주행 도움**을 켜면 핸들을 놓았을 때 길을 따라 달립니다. 직접 핸들을 움직여 방향을 바꿀 수 있습니다.
3. 게이트 세 곳에서 문제를 풀고 한 바퀴를 완주합니다. 정답은 부스터와 아이템을 줍니다.
4. 틀렸다면 해설을 읽고 **읽었어요 · 계속하기**를 누릅니다. 아이템은 Space 또는 화면 아이템 칸으로 사용합니다.
5. 길을 잃으면 **바로 세우기**를 누릅니다. 앞으로 순간 이동하지 않고 현재 진행 위치에서 방향을 바로잡습니다.
6. 완주하거나 **연습 마치기**를 누르면 학습 요약과 오답 노트를 볼 수 있습니다.

연습 친구들은 가상 카트입니다. 실제 학생이 아니며 내 카트를 막지 않습니다. 연습 기록은 탭 메모리에서만 사용하고 서버나 학생 스티커북에 보내지 않습니다.

## 수업에서 달라진 점
- 카트 설정에 **처음 주행 방식**이 추가됐습니다. 기본은 주행 도움이며 학생도 경기 중 켜고 끌 수 있습니다.
- 각자 진행하는 9개 게임은 **틀린 문제 다시 만나기**가 기본 켜짐입니다. 가능한 경우 다른 두 문항 뒤 다시 출제합니다. 오답이 많아도 새 문제를 계속 만나며, 문항이 아주 적으면 같은 문제를 더 빨리 만나게 됩니다. 골든벨과 뿅망치 대결은 기존의 공통 문제 진행을 유지합니다.
- 오답 뒤 해설은 학생이 읽고 넘깁니다. 게임 전체 시간은 계속 흐릅니다.
- 결과에는 **만난 문제 / 최근에 맞힌 문제 / 다시 도전해 성공 / 더 연습할 문제**를 표시합니다. 첫 시도 정답도 따로 표시해 단순 반복 득점과 구분합니다. 최근 정답은 그 개념을 완전히 습득했다는 판정이 아닙니다.
- **다시 생각하는 노트**에서 틀린 문제, 당시 답, 정답과 해설을 볼 수 있습니다. 복습 노트는 게임이 끝난 뒤 본인에게만 전송하며 점수를 바꾸지 않습니다.
- 교사가 결과를 저장하면 서버의 원본 응답 로그와 이벤트는 삭제됩니다. 학생 복습용 문항별 요약은 방을 닫거나 만료될 때까지 메모리에 남습니다. 서버 디스크에는 기록하지 않습니다.
- 답 시간은 서버에서도 확인합니다. 제한 시간 뒤 늦게 도착한 답에는 정답 보상을 주지 않습니다(전송 지연을 위해 1초 여유).

## 다른 PC로 내 세트 옮기기
Google Drive로 소스를 동기화해도 브라우저의 퀴즈 보관함은 자동으로 옮겨지지 않습니다. 같은 PC도 브라우저·접속 주소·포트가 다르면 별도 보관함입니다.

1. 기존 PC 보관함에서 **보관함 백업**을 누르고 JSON 파일을 저장합니다.
2. 그 파일을 Google Drive에 넣고 동기화 완료를 확인합니다.
3. 다른 PC에서 프로그램을 실행한 뒤 **보관함 복원**으로 파일을 고릅니다.
4. 기존 세트는 유지합니다. 제목과 문항이 완전히 같은 세트는 건너뛰고, 내용이 다른 세트는 새 복사본으로 추가합니다.

백업은 문제 세트만 담습니다. 학생 응답 기록, 교사 인증, 기록 폴더 권한, 학생 스티커북은 포함하지 않습니다. 수업 결과 JSON/엑셀은 기존 **결과 저장**을 별도로 사용하세요. 복원은 최대 5MB, 200세트, 세트당 300문항입니다.

## Windows 배포본
`release/JoyfulQuiz-v0.5.0-windows-날짜시간.zip`을 압축 해제한 뒤 안쪽 폴더의 `시작하기.cmd`를 실행합니다. `runtime/node.exe`가 포함되어 Node.js를 따로 설치하지 않아도 됩니다. Windows x64용입니다.

소스에서 직접 실행할 때는 Node.js 18 이상(개발 검사는 22 이상 권장)이 필요합니다. 실행 파일이 누락되면 인터넷 연결 후 `npm install`로 복구하세요. Drive가 파일을 잠그거나 복구가 느리면 로컬 폴더에서 의존성을 설치한 뒤 복사하거나, 배포본을 동기화 폴더 밖에 풀어 실행하세요.

수업 종료 → 서버 종료 → Drive 동기화 완료 → 다른 PC 실행 순서로 이동하세요. 진행 중인 방은 메모리에만 있어 서버 종료 후 이어지지 않습니다. 기록 폴더는 새 PC에서 다시 연결해야 합니다.
