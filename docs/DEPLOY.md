# 내일 수업에서 쓰기 — 세 가지 방법

어느 방법이든 **학생 기록은 서버에 저장되지 않아요.** 방은 서버 메모리에만 있고, 결과는 선생님 브라우저가 선생님 컴퓨터에 저장해요.

## A. 교실 와이파이 (가장 빠르고 안정적, 추천)
1. 선생님 PC에서 `시작하기.cmd` 더블클릭 → 선생님 화면이 열려요.
2. 대기실 화면의 주소(예: `192.168.0.6:3030`)나 QR로 학생이 들어와요. 학생 기기는 **같은 와이파이**여야 해요.
3. 수업 전 확인: 학생 기기 2~3대로 미리 들어가 보기. 안 되면 학교망이 기기끼리 연결을 막는 것일 수 있어요 → B나 C.
- Windows 방화벽 창이 뜨면 **개인/사설 네트워크**만 허용하세요.

## B. 인터넷 웹앱으로 배포 (Render, 무료, 주소가 계속 같음)
선생님 계정이 필요해요(GitHub, Render). 계정 만들기와 로그인은 선생님이 직접 해 주세요.
1. GitHub에 새 저장소를 만들고 이 폴더를 올려요 (`node_modules`는 빼고 — `.gitignore`에 이미 적혀 있어요).
   이 폴더는 이미 git 저장소예요: `git remote add origin <저장소 주소>` → `git push -u origin main`
2. https://render.com → **New → Blueprint** → 그 저장소 선택 → `render.yaml` 대로 만들어져요.
3. 환경 변수 `TEACHER_PIN` 에 선생님만 아는 숫자를 넣어요 (모르는 사람이 방을 못 만들게).
4. 몇 분 뒤 `https://joyful-quiz-xxxx.onrender.com/teacher.html` 이 선생님 화면이에요.
- 무료 요금제는 15분 동안 아무도 안 쓰면 잠들어요. **수업 5분 전에 선생님 화면을 한 번 열어** 깨워 두세요 (첫 접속에 30초~1분).
- 같은 방식으로 Dockerfile 을 지원하는 어느 곳(Fly.io, 학교 서버 등)에도 올릴 수 있어요. 인스턴스는 **1대**로 두세요 (방이 메모리에 있어서).
- 다른 주소로 QR을 보여 주고 싶으면 `PUBLIC_URL=https://주소/` 환경 변수를 넣어요.

## C. 임시 인터넷 주소 (계정 없이, 오늘만)
학교 와이파이가 기기끼리 연결을 막을 때, 선생님 PC를 잠깐 인터넷에 여는 방법이에요.
1. https://github.com/cloudflare/cloudflared/releases 에서 `cloudflared-windows-amd64.exe` 를 받아 `tools/cloudflared.exe` 로 넣어요.
2. `인터넷으로_열기.cmd` 실행 → PIN을 정하고 → 나온 `https://….trycloudflare.com` 주소에 `/teacher.html` 을 붙여 열어요.
3. 주소는 실행할 때마다 바뀌어요. 수업이 끝나면 창을 닫으세요.

## 수업 전 5분 점검
- [ ] 선생님 화면 열기 → 보관함에 오늘 세트가 있는지 (다른 PC면 엑셀로 옮기기)
- [ ] 💾 기록 폴더 연결 (크롬·엣지) — 결과가 그 폴더에 자동 저장
- [ ] 학생 기기 1대로 미리 들어가 보기 (게임 코드 → 이름 → 친구 고르기)
- [ ] TV 소리 켜기, 학생 기기는 기본 소리 꺼짐
- [ ] 끝나면 결과 화면의 📊 분석실로 다시 가르칠 문제 확인
