# v0.5 최종 검증 기록

검증일: 2026-10-29. 모든 브라우저 수업 자료는 예시 문제와 가상 학생입니다.

## 결과
- `npm test`: **83개 통과, 실패 0개**, 약 119초.
- `npm run check`: 의존성과 필수 파일 확인 통과.
- 실제 브라우저: 카트 운동장 연습 완주, 오답 해설 확인 후 계속, 연습 중단 후 개인 복습 노트, 교사·학생 방 진행과 결과, 교사 새로고침 후 저장 결과 복원 확인.
- 보관함 백업 파일 다운로드 및 같은 파일 복원 성공. 중복 세트는 추가하지 않음.
- 작은 화면은 개발용 390×844 iframe으로 연습 설정 배치를 확인했습니다. 실제 모바일 기기와 모든 화면 크기의 검증을 의미하지 않습니다. 화면 버튼 모드의 조작 버튼 표시도 확인했습니다.
- `docs/qa-v05/`에 연습장, 오답 해설, 복습 노트, 교사 화면 캡처를 남겼습니다. 원본 소스 폴더에서 볼 수 있습니다.

## Windows 배포본
- 파일: `release/JoyfulQuiz-v0.5.0-windows-20261029-232936.zip`.
- 포함 런타임: 공식 Node.js **v22.19.0 Windows x64**, 전체 라이선스 포함.
- ZIP을 Drive 밖의 새 임시 폴더로 압축 해제했습니다.
- 추출본의 `runtime/node.exe`로 `tools/doctor.mjs`와 `server.js`를 실행했습니다. 기본 설치 Node에 의존하지 않는 실행 경로를 확인했습니다.
- 검증용 포트 3041의 `/api/info`에서 버전 0.5.0과 게임 11종을 확인했습니다.
- 교사·연습장·학습 코드·카트 모델·3D 라이브러리·실시간 클라이언트가 모두 HTTP 200으로 응답했습니다.
- 추출본을 실제 브라우저에서 열어 **서버 준비 완료 → 혼자 카트 연습** 이동을 확인했습니다. 브라우저 오류 로그가 없었습니다.
- 마지막에 이 검증 문서만 ZIP에 추가합니다. 실행 코드와 자산은 압축 해제 검증한 것과 동일합니다. 최종 ZIP 옆의 `.sha256.txt`는 최종 파일 무결성 확인용입니다.

## 아직 확인하지 않은 범위
- 다른 물리 Windows PC의 더블클릭 실행, 실제 학교 Wi-Fi, 40대 태블릿 동시 접속.
- 운동장 외 4개 트랙의 전체 완주와 11종 게임 각각의 실제 수업.
- 온라인 배포. 이번 작업은 로컬 개선과 배포 파일 생성까지이며 기존 온라인 서비스에는 반영하지 않았습니다.

## 다른 PC에서 시작
1. ZIP을 로컬 폴더에 완전히 압축 해제합니다.
2. 안쪽 폴더의 `시작하기.cmd`를 실행합니다. 기본 포트는 3030입니다.
3. 문제 세트는 이전 PC의 **보관함 백업** 파일을 **보관함 복원**으로 가져옵니다.
4. 결과 기록 폴더는 새 PC에서 다시 연결합니다. 진행 중인 방과 브라우저 저장 내용은 Drive가 옮겨 주지 않습니다.
