# 즐거운 퀴즈 v0.2 디자인 방향 (모든 화면·모드 공통)

참고: Anthropic `frontend-design` 스킬(정체성·타이포·자기 비평 절차), 커뮤니티 `game-feel` 스킬(가벼움/보통/강함 3단 피드백).
퀴즈 카트의 모양(노랑·분홍 Jua 글꼴, 사진 배경, 3단계 줄)은 쓰지 않는다. Blooket·Gimkit의 **흐름**(세트 보관함 → 게임 상자 고르기 → 호스트 설정 → 큰 참여 배너 대기실 → 캐릭터)은 참고하되 겉모습은 우리 것.

## 콘셉트: "칭찬 스티커 공책"
교실의 모눈 공책 위에 스티커를 붙이며 노는 느낌. 굵은 잉크 테두리, 비뚤게 붙은 스티커, 형광펜 강조, 칭찬 도장.
기억에 남는 한 가지: **보상이 '쾅' 찍히는 도장/스티커** (정답·보상·순위 발표). 나머지는 단정하게.

## 글꼴
- 제목·숫자·버튼: **Do Hyeon** (OFL, `assets/fonts/dohyeon.woff2`, 한글 2,350자 부분 글꼴) → `var(--display)`
- 본문: 시스템 고딕 (`'Pretendard','Malgun Gothic','Apple SD Gothic Neo',system-ui`) → `var(--body)`
- 크기: 14 / 16 / 20 / 26 / 34 / 48 / 72 (TV는 한 단계 위)

## 모양
- 스티커 카드 `.sticker`: 흰 바탕, 3px 잉크 테두리, 18px 둥글기, 단단한 그림자 `4px 5px 0 var(--ink)`. 같은 줄 카드는 ±1° 비뚤게(--tilt).
- 버튼 `.btn`: 3px 잉크 테두리 + 아래 단단한 그림자 4px. 누르면 그림자만큼 내려감. 색 변형 `.blue .lemon .coral .mint .grape .ghost`. 크기 `.sm .lg .xl`.
- 형광펜 `.hl`: 글자 아래 절반만 노랑 칠.
- 마스킹테이프 `.tape`: 카드 위에 반투명 테이프 조각(보관함 세트 카드).
- 둥글기는 위계별로 다르게: 화면 패널 24, 카드 18, 버튼 14, 칩 999.
- 그림자는 흐린 회색 그림자 대신 잉크색 단단한 그림자.

## 움직임 (game-feel 3단)
`public/js/fx.js`:
- `fx.light(el)` 작은 반짝임 + 높은 '딸깍' (보기 고르기, 버튼)
- `fx.medium(el, text)` 색종이 8~14개 + 떠오르는 숫자(+50) + 살짝 튕김 (정답, 골드 획득)
- `fx.heavy(text)` 화면 흔들림 120ms + 하얀 번쩍 + 큰 도장 '쾅' + 낮은 '쿵' (대박, 1등, 보스 처치)
- `fx.stamp(text, color)` 칭찬 도장 찍기 애니메이션
- `fx.float(el, text, color)` 떠오르는 글자, `fx.shake(el)` 오답 흔들기
- 소리 높낮이: 작은 것 높게, 큰 것 낮게. 움직임 줄이기 설정이면 흔들림·번쩍 생략.

## 캐릭터 "스티커 친구들"
`public/assets/chars/<id>.png` (512px 투명, Blender). `public/js/chars.js`에 목록(id, 이름, 등급 일반/희귀/전설, 대체 이모지).
아바타 = `{ char: 'fox', color: '#3D8BFF', hat: 0 }` (예전 `face` 이모지는 대체용으로 계속 둠). 흰 테두리 스티커 효과: `filter: drop-shadow(0 0 0 #fff) ...`.

## 글쓰기
아이에게는 짧은 반말 존댓말 섞지 않고 "~해요". 버튼은 하는 일 그대로("방 열기", "게임 시작", "결과 저장"). 오류는 무엇이 잘못됐고 어떻게 고치는지.
