# 🎣 낚시 대회 (fishing)

각자 진행 · 개인전. 점수 = 낚은 무게 합계(kg, 소수 한 자리).

## 규칙
1. 문제를 맞히면 **던지기** 버튼(또는 스페이스)이 나와요. 6초 안에 안 누르면 저절로 던져요.
2. 찌가 물에 떨어지고 잠시 뒤 **입질!** → 바늘이 막대 위를 왔다 갔다 해요.
   - 가운데 노랑 칸: **완벽** ×1.5 · 초록 칸: **좋아요** ×1.2 · 그 밖/6.5초 지남: ×1.0
   - 실패는 없어요. 언제나 물고기를 받아요. 귀한 물고기일수록 바늘이 빨라요.
3. 틀리면 "🧶 줄이 엉켰어요" 하고 다음 문제로.
4. **미끼(1~5)**: 연속 2번 맞힐 때마다 +1, 틀리면 -1. 미끼가 좋을수록 귀한 물고기가 잘 나와요.
5. 목표 무게(설정)에 먼저 닿으면 2.5초 뒤 끝. 아니면 게임 시간까지.
6. 던지지 않았거나 감지 않은 물고기는 다음 문제를 받을 때·게임이 끝날 때 ×1.0 으로 자동으로 낚아요(새로고침·연결 끊김 대비).

## 물고기 (기본 무게 kg, 감기·물고기 떼 보너스 전)
| 등급 | 물고기 |
|---|---|
| 흔한 물고기 | 송사리 0.3–1.5 · 금붕어 0.5–2.2 · 고등어 1.2–3.8 · 붕어 2–6 |
| 희귀 | 흰동가리 1–3.5 · 복어 3–8 · 오징어 4–10 · 무지개송어 5–12 |
| 대어 | 문어 10–25 · 황새치 20–45 |
| 전설 | 아기고래 40–80 · 황금 잉어 30–60 (이벤트 때는 40–70) |
| 잡동사니 | 낡은 장화 0.1–0.6 · 빈 깡통 0.1–0.3 (웃긴 한마디) |

등급 확률(미끼 1 → 5): 흔한 70→30%, 희귀 20→40%, 대어 4→20%, 전설 0.6→5%, 잡동사니 5% 고정.
그림: `public/assets/fish/<id>.png` (없으면 이모지 🐟🐠🐡🦑🐙🐋🦈👢🥫).

## 반 전체 이벤트 (설정 "물고기 떼 이벤트" 켜기)
- 첫 이벤트는 시작 후 60~80초, 그다음은 대략 75~100초마다. 5초 전에 예고 띠.
- **🐟 물고기 떼** 15초: 그동안 낚은(또는 그동안 맞혀서 곧 던진) 물고기 무게 ×2.
- **✨ 황금 잉어 출현** 20초: 가장 먼저 물고기를 건 한 명이 황금 잉어(40–70kg)를 받아요. 아무도 못 낚으면 도망.
- 물고기 떼 2번 뒤에는 꼭 황금 잉어, 황금 잉어 뒤에는 물고기 떼. 끝나기 직전에는 이벤트 없음.
- 선생님 TV의 "🐟 물고기 떼 부르기"·"✨ 황금 잉어 부르기"로 언제든(설정이 꺼져 있어도) 부를 수 있어요.

## 소켓 메시지
- 학생 → `s:mode`: `cast` → `{catch:{id,name,rarity,base,frenzy,koi}}` (다시 보내면 같은 물고기 `again:true`), `reel {quality:'perfect'|'good'|'miss'}` → `{res:{kg,quality,isNew,total,msg...}, lure, xp, dex}` (물고기가 없으면 error), `state`
- 교사 → `t:mode`: `event {kind:'frenzy'|'koi'}`, `endnow`
- 서버 → 모두: `start {endsIn}`, `board {top, all:[[pid,kg,count]], big, endsIn, total, catches, ev, goal}`(1~3초마다), `event {id,kind,phase:'warn'|'on',startsIn,leftMs}` / 끝 `{kind:null, ended, winner, escaped}`, `koi`, `goal`
- 서버 → 학생: `lure {lure,xp,up,down,tangled}`, `big`(다른 친구 전설 물고기) · 교사: `catch {...res, pid, player}`
- 시간은 모두 "남은 ms"로 보내요(기기 시계가 달라도 맞게).
- 순위 extra: `{correct, answered, kg, count, biggest:'아기고래 52.3kg'}`
