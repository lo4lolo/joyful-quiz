# 🏎️ 퀴즈 카트 레이스 (mode id: `race`)

## 파일
| 파일 | 하는 일 |
|---|---|
| `server/modes/race.js` | 서버 규칙: 출발·위치 중계(snap)·문제 보상·아이템·도착 판정·순위 |
| `public/js/race/tracks.js` | 트랙 5개(순수 수학, 서버·학생·교사 공용): 곡선, 진행도, 게이트·상자·출발 자리 |
| `public/js/race/game3d.js` | three.js 3D 게임(학생 운전 / 교사 중계 카메라) |

## 조종
- PC: ←→ / A D 핸들, ↑ / W 가속, ↓ / S 브레이크·후진, **Shift**(또는 X) 드리프트, **Space**(또는 E) 아이템
- 태블릿(`device:'touch'`): 왼쪽 동그라미 핸들, 오른쪽 💨 드리프트 · ✋ 멈춤 · 아이템 칸. **자동 가속**이 기본으로 켜져 있음(끄면 핸들을 위로 = 가속)
- 드리프트를 길게 하면 파란 불꽃(💨 터보) → 주황 불꽃(🔥 미니 터보), 놓으면 부스터
- 출발 "1" 때 가속을 누르고 있으면 🚀 로켓 출발

## 규칙
- 출발 4초 카운트다운(준비~ 3·2·1 출발!) 뒤에 달림.
- **❓ 퀴즈 게이트**: 바퀴마다 `gates`개. 지나가면 카트가 자동으로 천천히 달리며 문제가 나옴.
- **🎁 아이템 상자**: 게이트 사이에 4개씩 한 줄. 부딪히면 문제가 나옴(6초 뒤 다시 생김).
- 맞히면 🚀 부스터 + 아이템 1개(칸이 비어 있을 때). 틀리면 1초 동안 살짝 느려짐(벌은 이것뿐).
- **🎫 퀴즈 도장** = 푼 문제 수(맞든 틀리든, 시간 초과도 1개). `stamps`개 이상 + `laps`바퀴를 돌아야 도착.
  도장이 모자라면 결승선에서 "퀴즈 도장이 n개 더 필요해요!"가 나오고 한 바퀴 더 돌 수 있음(게이트는 바퀴마다 다시 켜짐).
  게이트 0개이고 상자도 끄면 도장 조건은 자동으로 0.
- 아이템(서버가 굴림, 앞선 학생은 방어용, 뒤처진 학생은 따라잡기용이 더 잘 나옴)
  - 🚀 부스터 1.8초 · ⭐ 별 5초(무적+빨라짐) · 🛡️ 방패 12초(바나나·먹물 한 번 막음)
  - 🍌 바나나: 뒤에 놓음. 밟으면 1.2초 빙글. · 🦑 먹물: 나보다 앞선 친구들 화면에 4초 먹물
- 바퀴 세기: 체크포인트 8개를 차례로 지나야 한 바퀴. 도로 밖 6m에 부드러운 벽(타이어)이 있어 지름길이 없음. 거꾸로 달리면 "거꾸로 가고 있어요!"
- 끝나는 때: 접속한 학생의 `finishPct`%가 도착하면 8초 뒤 끝(모두 도착하면 3초 뒤). 최대 시간 = 바퀴 수 × 4분.
  교사 "🏁 지금 끝내기" = 5초 세고 끝, 5초 안에 한 번 더 누르면 바로 끝.

## 설정 (`settings`, 교사 화면 설정 폼용)
| 키 | 한국어 이름 | 값 | 기본 |
|---|---|---|---|
| `track` | 트랙 | 0 운동장 서킷 🏫 · 1 사막 협곡 🏜️ · 2 눈꽃 마을 ⛄ · 3 우주 정거장 🚀 · 4 바닷가 🏖️ · -1(또는 'random') 무작위 | 0 |
| `laps` | 바퀴 수 | 1~5 | 3 |
| `gates` | 바퀴마다 퀴즈 게이트 | 0~4 | 3 |
| `stamps` | 도착에 필요한 퀴즈 도장 | 0~6 | 2 |
| `finishPct` | 몇 % 도착하면 끝낼까요 | 30 · 50 · 100 | 50 |
| `items` | 아이템 쓰기 | true/false | true |
| `boxes` | 아이템 상자(상자도 문제를 냄) | true/false | true |
(공통 `time` = 문제 제한 시간도 그대로 씀. 레이스에는 10~20초를 권장)

## 점수 (`ranking`)
- 순위(rank): 도착한 학생은 기록 순, 못 한 학생은 달린 거리(rp) 순.
- 점수(score) = 맞힌 문제 × 100 + 순위 보너스
  - 도착: 200 + (10등 안이면 (11 − 등수) × 30) → 1등 500, 2등 470 … 10등 230, 11등부터 200
  - 도착 못 함: 달린 비율 × 150 (최대 150)
- `extra`: `{ time(ms|null), finished, stamps, correct, lap }`

## 네트워크 이벤트
학생 → 서버 (`s:mode {type, data}`)
- `sync` → ack: 현재 상태(snapshot). 모드 화면이 열리면 한 번 부름.
- `st {x,z,h,s,rp,fx}` 10번/초(안 움직이면 2번/초), ack 없음(`socket.emit` 직접). rp = 바퀴 + 진행도(출발선 0, 한 바퀴 1).
  fx 비트: 1 부스터, 2 방패, 4 별, 8 빙글, 16 드리프트, 32 큰 드리프트, 64 퀴즈 중, 128 먹물, 256 도착
- `item {kind, x?, z?}` → ack `{ok}` / `{error:'noitem'}` (서버가 가진 아이템만 쓸 수 있음)
- `banana:hit {id}` · `finish {lap, rp}` → ack `{ok, rank, time}` / `{error:'laps'|'fast'|'stamps', need}`
- 문제는 공통 `s:ask`/`s:answer`. `canAsk`: 출발 뒤, 도착 전, 끝내기 카운트 전, 지난 답 1.2초 뒤.

교사 → 서버 (`t:mode`): `sync` → snapshot(+`stats {pid:[stamps,correct]}`) · `endnow {soon?}`

서버 → (`m {type,data}`)
- 모두: `start {track,laps,gates,stamps,items,boxes,goIn,maxIn,closeIn,roster:[[pid,k]]}`, `snap [k,x*10,z*10,h*100,s*10,rp*1000,fx, …]`(100ms, 바뀐 카트만),
  `roster {pid,k}`(경주 중 새로 들어온 학생), `banana:add {id,x,z,by}`, `banana:del {id,k?}`, `use {k,kind}`, `finish {pid,k,rank,time,name}`, `closing {endIn}`
- 한 학생: `reward {ok, item, full, boost, stamps, correct, penalty?}`, `ink {from}`
- 교사: `stat {pid, stamps, correct}` (+ 공통 `feed`, `log`)
- 시간은 모두 "지금부터 몇 ms"(goIn, closeIn)로 보내 기기 시계가 달라도 괜찮음.

## 성능
- 카트 40대: 가까운 10대만 GLB 모델, 나머지는 인스턴스 상자 1번 그리기. 이름표는 가까운 14명만(HTML).
- 장식·타이어 벽·상자·바나나·그림자·구름·산은 모두 InstancedMesh. 실시간 그림자 대신 둥근 그림자.
- 픽셀 비율 최대 1.5(저사양·터치 기기는 1, 안티앨리어싱 끔). 2초마다 fps를 재서 28 아래면 픽셀 비율을 0.2씩 내림(최저 0.6).
- 물리는 1/60초 고정 단계. 벽은 도로 중심선 기준 거리로 막아서 뚫고 지나갈 수 없음.
- 모델(`public/assets/models/*.glb`)이 없거나 깨져도 간단한 도형으로 대신 그림.

## 알려진 한계
- 운전·충돌은 학생 브라우저가 판정(교실용으로 단순화). 서버는 최소 시간(바퀴당 12초)·바퀴 수·도장만 확인.
- 카트끼리 부딪힘은 내 카트만 밀려남(상대는 그대로).
- 바나나 판정은 밟은 학생 기기 기준. 별(⭐) 상태로 다른 카트를 날리는 기능은 없음.
- 3D 중계 카메라는 선두를 2.5초마다 다시 골라 따라감(수동 선택 없음).
- WebGL이 안 되는 기기는 안내 문구만 나옴(2D 대체 화면 없음).
