# v0.6 UI/UX 개선 근거와 적용 범위

검토일: 2026-10-29~30. 기존 ‘칭찬 스티커 공책’ 디자인과 11종 게임을 유지하고 교사의 준비·진행 흐름을 개선했습니다.

## 참고한 GitHub 공개 가이드
- [UI UX Pro Max 원본 저장소](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill): 접근성, 명확한 입력·피드백, 반응형 배치, 제품 맥락에 맞는 일관성을 검토하는 참고 자료.
- [UI UX Pro Max 가이드 원본](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill/blob/main/src/ui-ux-pro-max/templates/base/skill-content.md): 기존 UI의 실제 문제부터 좁혀 검토하는 방법. 모바일 앱 전용 조항은 웹 화면에 일괄 적용하지 않았습니다.
- [GitHub Primer: Focus management](https://primer.style/accessibility/design-guidance/focus-management/): 키보드로 접근 가능한 제어, 보이는 초점, 자연스러운 순서와 대화상자 종료 후 초점 복귀.
- [GitHub Primer: Dialog accessibility](https://primer.style/product/components/dialog/accessibility/): 제목이 있는 모달, 내부 Tab 순환, Esc 취소, 배경 접근 억제.
- [GitHub Primer: Motion and animation](https://primer.style/accessibility/design-guidance/motion-and-animation/): 의미 있는 움직임과 동작 줄이기 선호 존중.

외부 스킬을 설치하거나 저장소의 스크립트를 실행하지 않았습니다. 공개 문서를 설계 참고로 읽었고 구현은 기존 HTML/CSS/JS 구조에 맞춰 작성했습니다. 가이드에 등장하는 앱 전용 아이콘·스택 권고를 기계적으로 적용하지 않고, 이 프로젝트의 문자 라벨과 익숙한 게임 그림을 유지했습니다.

## 실제 변경
| 사용 중 문제 | 변경 | 확인 방법 |
|---|---|---|
| 첫 수업의 출발점이 여러 버튼으로 흩어짐 | 예시 수업 준비 버튼, 4단계 진행 위치, 가까운 가이드 링크 | 예시 → 게임 → 설정 → 대기실 |
| 세트가 늘면 찾기 어려움 | 제목·문항 검색, 최근 수정/이름 정렬, 0건 안내 | 문항 검색, 없는 검색어, 검색 초기화 |
| 자동 저장을 알기 어려움 | 저장 중/저장됨/실패 표시, 페이지를 떠날 때 저장 | 입력 → 저장 상태 → 새로고침 후 복원 |
| 문제나 정답이 빠진 줄이 출제에서 조용히 제외됨 | 게임 선택 전 문항 검증, 수정 위치 링크, aria-invalid | 정답 없는 문항 → 안내 초점 → 수정 → 게임 선택 |
| 좁은 입력 표에서 답과 해설을 읽기 어려움 | 입력 최소 폭과 높이, 표 내부 가로 스크롤, 중간 화면에서 미리보기 아래 배치 | 1280px 편집 화면 |
| 숨긴 파일 입력의 라벨은 키보드로 찾기 어려움 | 실제 버튼으로 엑셀·백업 파일 선택 | 복원 버튼 Enter → 파일 선택 → 중복 세트 생략 확인 |
| 설정·AI 창에서 초점을 잃기 쉬움 | 공통 모달 초점 관리, Esc 취소, 배경 inert | 열기 → Tab 순환 → Esc → 원래 버튼 |
| 카트 설정을 한 번에 너무 많이 제시 | 주요 설정 우선, 게이트·결승·아이템은 현재값 요약과 펼치기 | 자세히 설정을 열고 값 변경 |
| 선택 상태가 색에만 의존 | 설정 버튼 aria-pressed와 문구 유지 | 선택 상태와 접근성 트리 확인 |
| 교사 버튼의 흰 글자와 밝은 배경 대비 부족 | 교사 파랑·보라·위험 버튼을 더 어둡게, 44px 조작 높이 | 색 대비 계산과 화면 확인 |
| 작은 화면에서 메뉴가 이모지만 남음 | 메뉴 글자·서버 상태를 유지 | 작은 폭의 개발용 프레임에서 확인 |
| 움직임을 줄이고 싶은 사용자 | 교사 화면과 가이드의 reduced-motion CSS | 스타일 규칙 확인; 실제 OS 선호 변경은 미검증 |

## 교사용 가이드
`public/teacher-guide.html`: 8개 장, 실화면 5장, 11종 게임 선택표, 입력·저장 비교표, 8개 도움말 검색, 수업 전 체크, 인쇄 스타일.

`npm run guide`는 그림·글꼴·스타일·스크립트를 포함한 `교사용_사용가이드_v0.6.html`을 생성합니다. 인터넷 없이 읽을 수 있으며 게임 연결은 기본 로컬 주소 3030을 사용합니다. 실제 게임은 서버를 먼저 켜야 합니다.

이 문서는 WCAG 전체 적합성 인증을 의미하지 않습니다. 실제 스크린리더, 다양한 OS·실물 태블릿, 인쇄기의 페이지 배치는 추가 검증 대상입니다. 최종 검증 결과와 다음 작업은 v0.6 인수인계서를 참조하세요.
