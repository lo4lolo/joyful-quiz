# ⭐ 즐거운 퀴즈 v0.6
**아이들은 즐겁게 퀴즈를 풀고, 선생님은 깊이 있게 분석하는** 교실용 단원 정리 퀴즈입니다.
정답률만이 아니라 오개념·응답 시간·다시 만난 문제·게임 속 행동·모둠 협력까지 분석실에서 살펴 다음 수업을 설계해요.
학생 기록은 수업 중 서버 메모리에서 처리하며 서버 디스크에는 저장하지 않습니다. 장기 보관은 **선생님 컴퓨터의 결과 파일**로 합니다. 복습용 요약도 방이 닫히면 삭제됩니다.

## 내일 수업에서 바로 쓰기
**[교사용 사용 가이드](교사용_사용가이드_v0.6.html)** — 그림·글꼴을 포함한 한 파일입니다. 서버나 인터넷 없이 읽을 수 있습니다. 앱 안에서도 ‘교사용 가이드’로 열 수 있습니다.

v0.6: 첫 수업 안내, 세트 검색·정렬, 저장 상태, 문항 누락 안내, 키보드 대화상자, 간결한 카트 설정을 추가했습니다. [UI/UX 참고와 적용 근거](docs/UIUX_V06.md) · [최신 인수인계](docs/HANDOFF_V06_2026-10-30.md)

처음이면 보관함의 **🏎️ 혼자 카트 연습**으로 5개 트랙과 퀴즈 게이트를 익혀 보세요. 학생 초대 없이 실행됩니다.

v0.5: 주행 도움·바로 세우기, 오답 다시 출제, 개인 학습 요약·복습 노트, 퀴즈 보관함 백업/복원, Windows 실행 파일 포함 배포본. [자세한 사용 안내](docs/V05_GUIDE.md)

1. **시작하기.cmd** 더블클릭 → 선생님 화면 (http://localhost:3030/teacher.html). Windows 배포본에는 실행 프로그램이 포함되어 있습니다. 소스만 받았다면 Node.js 18 이상 필요.
2. **퀴즈 세트** 만들기 (표에 쓰기 · 엑셀 올리기 · 🤖 AI 요청문 복사) — 처음이면 "예시 · 지층과 화석"으로.
3. **게임 열기** → 게임 상자 고르기 → 설정 → **방 열기**. TV에 주소·게임 코드·QR.
4. 학생: 게임 코드 → 이름 → 스티커 친구 고르기. 모둠 게임이면 대기실에서 **모둠 수**를 고르세요.
5. **게임 시작** → 끝나면 결과가 선생님 컴퓨터에 자동 저장 → **📊 분석실**.

교실 와이파이가 막히거나 인터넷 주소가 필요하면 [docs/DEPLOY.md](docs/DEPLOY.md) (Render 배포 · 임시 인터넷 주소).

## 모둠 협력 설계 (선생님 박사 연구 자료 기반) — [docs/COOP_DESIGN.md](docs/COOP_DESIGN.md)
전원 대 게임(도깨비) · **서로 다른 모둠원 n명**의 정답이 있어야 진행 · 역할은 기능 차이로만, 돌아가며 · 개인 순위 대신 "모둠에 보탠 몫" · 탈락 없음 · **교사 알림**(정체 4분, 연속 오답 2, 기여 15% 미만, 독주 50% 초과; 게임당 12건 이하) · 학생 **성찰** · 협력 이벤트를 기록 파일 `events`에 저장 → 분석실 **🤝 모둠 협력**(참여 형평성, 기여 0명, 균형 지수, 성찰, 알림→교사 도착).

## 보안·개인정보
- 서버는 방을 **메모리에만** 둡니다. 방을 닫으면 바로, 아니어도 4시간 뒤 지워집니다. 디스크·DB 저장 없음.
- 정답은 서버만 압니다. 학생은 받은 문제에 한 번만 답할 수 있습니다.
- **별명 모드**: 친구·TV에는 재미있는 별명, 선생님 기록에는 실제 이름. **입장 잠금**. 인터넷 배포 시 **선생님 PIN**.
- 결과는 선생님 브라우저가 선생님 컴퓨터에 저장(💾 기록 폴더 연결 시 그 폴더). 분석실은 파일을 브라우저 안에서만 엽니다.
- 학생 스티커북(칭찬 도장·뽑기)은 학생 기기에만 저장됩니다.
